# 简历助手

纯前端的中文简历制作工具：9 套模板、**真实 A4 分页的所见即所得预览**、智能一页、多份简历管理，一键导出 PDF。零依赖、无需构建，数据只保存在本机浏览器。

## 打开网站https://freadchips.github.io/Resume-Helper/  即可使用

## 功能

### 编辑
- **结构化栏目**：经历型（工作 / 教育 / 项目 / 实习 / 校园 / 奖项）、文本型（简介 / 自我评价）、标签型（技能）、列表型（证书 / 语言），也可添加自定义栏目
- **行内编辑**：栏目名直接点击修改；经历条目可折叠，折叠时显示摘要
- **拖拽排序**：栏目、条目、联系方式均可拖动（鼠标与触屏都支持），也可用菜单上移 / 下移
- **临时隐藏**：栏目或单条经历可隐藏而不删除，方便为不同岗位裁剪内容
- **字段设置**：经历型栏目可开关副标题 / 时间 / 地点 / 描述，并自定义字段名称
- **联系方式与个人信息**：电话、邮箱、微信、GitHub、年龄、籍贯、政治面貌、期望薪资等 16 种类型 + 自定义
- **轻量排版标记**：`**加粗**`、`*斜体*`、`[文字](链接)`，以 `- ` 开头的行自动成为列表，回车自动续写
- **照片**：点击或拖入上传，自动压缩，避免撑满浏览器存储
- **撤销 / 重做**：所有修改都可撤销；删除操作提供“撤销”提示
- **点击预览定位**：点击右侧简历中的任意内容，左侧自动跳到对应编辑位置

### 模板与排版
| 模板 | 特点 |
| --- | --- |
| 经典 | 原版风格：纵向排列、照片居右、蓝色标题线 |
| 现代 | 深色侧栏承载联系方式与技能 |
| 简约 | 标题置于左栏、留白充足，适合技术岗 |
| 商务 | 通栏色带页眉、标签式栏目标题 |
| 时间轴 | 左侧彩条与经历时间线 |
| 雅致 | 衬线字体、居中对称 |
| 清新 | 通栏页眉 + 浅色右侧栏 |
| 杂志 | 超大姓名、01/02 编号标题、日期置于左栏、页脚页码，杂志版式 |
| 东方 | 竖排姓名色条、印章式栏目标题、菱形列表符，东方韵味 |

- 10 种预设主题色 + 任意自定义颜色
- 字体（黑体 / 宋体）、字号、行距、段落间距、页边距均可调节，可一键恢复模板默认
- **智能一页**：自动微调排版参数，把内容收进一页 A4
- 双栏模板中可指定每个栏目放在主栏或侧栏

### 预览与导出
- 预览按真实 A4 尺寸分页：块级内容不会被页面切断，超长条目按行拆分，栏目标题不会孤立在页尾
- **下载 PDF**：使用浏览器打印 → 另存为 PDF，输出与预览完全一致（推荐 Chrome / Edge）
- **导出网页（HTML）**：单文件，可直接发送；文件内含简历数据，可再次导入继续编辑
- **备份数据（JSON）**：用于换设备或换浏览器
- **导入**：支持本工具的 JSON / HTML、旧版本备份，以及 [JSON Resume](https://jsonresume.org/) 格式

### 数据
- 多份简历管理：新建、复制、重命名、删除，可为不同岗位分别维护
- 自动保存到本机浏览器（localStorage），保存失败（如存储已满）会明确提示
- 首次打开时自动迁移旧版本保存的数据

## 快速开始

```bash
npm run dev        # 启动本地服务 http://127.0.0.1:8765
npm test           # 发布前检查
```

没有 Node.js 时可用 Python：`py -m http.server 8765 --bind 127.0.0.1`（macOS / Linux 用 `python3`）。

也可以直接双击打开 `index.html` 使用；此时除“导出 HTML”（需要读取样式文件）外，其余功能均可用。

## 测试

- `npm test`：在 Node 中检查资源引用、脚本语法、模板完整性，并运行数据迁移、导入、模板渲染、撤销重做等逻辑测试
- 浏览器打开 `/tests/`：运行全部测试，包括依赖真实布局的分页测试（跨页拆分、标题防孤立、智能一页等）

```
my-resume/

├── css/
│   ├── app.css             # 编辑器界面（含深色模式、移动端）

│   ├── core/

│   │   ├── icons.js        # 线性图标
│   │   ├── schema.js       # 数据结构、栏目预设、示例数据、旧版迁移与导入

│   │   └── store.js        # 多简历存储、撤销重做、自动保存

│   │   ├── templates.js    # 模板定义与公共块构建
│   │   ├── paginate.js     # A4 分页引擎、智能一页
│   │   └── preview.js      # 预览缩放与交互
│   ├── ui/
│   │   ├── components.js   # 模态框、菜单、提示、拖拽排序
│   │   ├── editor.js       # 内容编辑面板
│   │   └── design.js       # 模板与排版面板
│   └── app.js              # 入口：顶栏、导入导出、快捷键、打印
├── tests/                  # 测试用例与浏览器测试页
├── scripts/                # 本地服务器、发布前检查
├── netlify.toml / vercel.json
└── package.json
```

### 新增模板

1. 在 `js/render/templates.js` 中 `templates.register({...})`：提供 `page(i, ctx)`（页面骨架，含 `[data-col]` 栏位）与 `flows(ctx)`（各栏位的内容块）
2. 在 `css/resume.css` 中添加 `.tpl-<id>` 样式
3. 在 `js/ui/design.js` 的 `THUMBS` 中添加缩略图

`npm test` 会检查每个模板是否都有样式和缩略图。

## 部署

纯静态站点，根目录即发布目录：

- **Netlify**：导入仓库即可，`netlify.toml` 会执行 `npm test` 并发布当前目录
- **Vercel**：导入仓库即可，使用 `vercel.json`
- **任意静态托管**：上传 `index.html`、`css/`、`js/` 即可

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl/⌘ + Z`、`Ctrl/⌘ + Shift + Z` | 撤销 / 重做（输入框外） |
| `Ctrl/⌘ + P` | 下载 PDF |
| `Ctrl/⌘ + S` | 立即保存 |
| `Ctrl/⌘ + B` | 描述中加粗选中文字 |

## 浏览器兼容

Chrome / Edge / Firefox / Safari 的近期版本。PDF 导出推荐 Chrome 或 Edge。
